Sync Box setup

Five steps. You can rerun this from Advanced.

1. Your TV

2. LED counts

Count the LEDs you actually mounted on each edge, seen from the front of the TV.



3. Calibrate
Each button lights the whole strip in one colour for 20 s. The engine's layout editor (Advanced) shows which LEDs map where; if the picture appears rotated or mirrored later, change the start corner or direction in step 2 and resend.







4. Philips Hue (optional)
Hue is driven by the engine's built-in Hue Entertainment output. Open the engine page, LED Hardware, add a second instance with controller type "philipshue", press the bridge button when asked, and pick your Entertainment Area. This is marked untested in this project until you confirm it.





5. Finish
The box now boots straight into sync. After a few days of use, lock the SD card read-only from Advanced.
